# 3단계 · 바느질 인터랙션과 원본 비쳐 보기

`quilt.html`에서 조각보가 다 꿰매진 채로 나오지 않고, 조각들이 자리에서 조금씩 비켜난 채 펼쳐져 나온다. 솔기는 직접 꿰매야 이어진다.

| 메커니즘 | 어떻게 | 왜 |
|---|---|---|
| 흐트러진 자투리 | 꿰매지 않은 덩어리는 자리에서 최대 9단위, 2.2° 비켜나 있다. 덩어리가 클수록 1/√n만큼 덜 흐트러지고, 다 이으면 0 | 아직 내 것이 아닌 조각은 제자리에 붙어 있지 않다. 큰 판은 무게로 바닥에 붙는다 |
| 시침질 | 지금 꿰맬 수 있는 솔기에만 성긴 붉은 임시 실을 그린다 | 바느질 전에 시침질로 자리를 잡아 두는 실제 순서. 어디를 꿰맬지 말없이 알려 준다 |
| 꿰매는 순서 | 양쪽 덩어리가 각각 다 이어져 있어야 그 사이 솔기가 열린다 (가위질의 역순) | 실제 조각보도 작은 조각을 이어 줄을 만들고, 줄을 이어 판을 만든다 |
| 땀 뜨기 | 시침실 위를 누르고 솔기를 따라 그으면 손이 지나간 자리에만 땀이 생긴다. 솔기에서 손이 멀어지면 실이 끊기고, 같은 자리를 다시 그어도 땀이 겹치지 않는다 | 이어 붙이는 수고가 그대로 천에 남는다 |
| 손의 속도 | 느리게 그으면 땀이 짧고(3.2) 고르며, 빠르게 그으면 길고(최대 10.2) 성기고 삐뚤다 | 같은 조각보라도 꿰맨 사람의 손이 남아, 그 조각보가 그 사람의 것이 된다 |
| 마무리 | 90%를 넘게 그으면 남은 틈을 바늘이 마저 채우고, 두 덩어리가 제자리로 당겨져 붙는다 (모바일은 짧은 진동) | 마지막 몇 땀까지 정확히 맞추라고 하지 않는다. 붙는 순간이 손에 느껴지도록 |
| 원본 비쳐 보기 | 데스크톱은 조각 위에 올리면, 모바일은 길게(0.42초) 누르면 사진이 천 아래에 깔리고 천이 얇아진다 | 사진은 천 너머로만 본다. 기억은 장면이 아니라 색으로 남아 있고, 가까이 다가가야 장면이 비친다 |

꿰맨 땀은 덩어리와 함께 움직인다. 같은 기억으로 다시 지어도 꿰맨 사람의 손이 다르면 땀이 다르다.

## 검증

- `npm test`: 처음엔 작은 솔기만 열린다, 큰 솔기는 안쪽을 다 꿰맨 뒤에 열린다, 땀은 지나간 자리에만 생긴다(겹쳐 그어도 늘지 않음), 90%에서 완성된다, 빠르면 땀이 성기다, 꿰매면 두 덩어리가 같이 움직인다.
- `npm run e2e`: 데스크톱 브라우저에서 마우스로 솔기 35개를 모두 따라 그어 완성하고, 잠긴 솔기와 반만 그은 솔기는 붙지 않는지, 조각 위에 마우스를 올리면 원본이 비치는지 확인.

## 아직 확인 못 한 것

- 실제 휴대폰에서의 길게 누르기와 손가락 드래그 감각 (자동 테스트는 마우스로만).
- 솔기가 아주 짧은 조각(삼각 조각의 짧은 변 등)에서 손가락으로 잡기 쉬운지.
- 꿰맨 상태는 아직 저장되지 않는다. 새로고침하면 처음부터.
